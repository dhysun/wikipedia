# Local Hosting - Wiki-Pathfinder

## Step 1: Copy files

Copy all the files from [wiki-pathfinder] (#https://github.com/dhysun/wikipedia/tree/main/wiki-pathfinder) onto a local folder.

## Step 2: Copy binary files

Copy all files from the ".bin files" folder of [this] (#https://drive.google.com/drive/folders/1zovQapluH6LGg_0V8Q7cpqaH-F0wSjCb?usp=drive_link) Google Drive folder into a folder called "data". The local folder should contain the folders data, static, and templates, and the files app.py and WikiGraph.py

## Step 3: Install the appropriate python packages

Install the flask and numpy Python packages with the following command in terminal: "python -m pip install numpy flask"

## Step 4: Run a local instance of wiki-pathfinder

Now, simply run the file app.py (this will likely require ~2.5 GB of RAM)!
