## k_shortest_paths()

k_shortest_paths() is a modified implementation of Yen's algorithm that uses a Bidirectional BFS as its shortest-path algorithm (as the edges are inherently unweighted). After the shortest path between two articles is found, each node (excluding the start and end) is tested as a "spur node", where the algorithm attempts to find an alternate path to the end starting from that node (by disallowing edges and nodes). Paths that are found this way are pushed onto a min heap based on path length, and then added to candidate_set (which is also used to track any duplicate paths). The shortest path in the heap becomes a new confirmed path, and the cycle repeats using the new confirmed path as a source of spur nodes.

Forbidden edges are generated by comparing the current root path to an already confirmed path; if the confirmed path shares the same root path, then all edges after the root path for the confirmed node are marked forbidden. All nodes before the root_path node are also forbidden to eliminate backtracking. Notably, because removing nodes and edges is impractical for the CSR representation of the graph, the sets forbidden_edges and forbidden_nodes are used instead to track nodes and edges that should not be revisited. There are also multiple timeout "checks" throughout the function to enforce a specified time limit (ten seconds for the website), which forces an early return, and a timeout flag to indicate whether the algorithm terminated due to a timeout.

## BiBFS()

BiBFS() is a standard bidirectional BFS that maintains a separate visited list and queue for the forward and backward frontiers, exploring frontiers based on which corresponding queue is shorter. BiBFS() keeps track of the path that the frontiers take through a forward and reverse path dictionary that maps a node to its incoming edge found during exploration. The final path is reconstructed by taking the meeting point of the two frontiers and following the forward and reverse path dictionaries to the start and end nodes, respectively. BiBFS() uses extend() as a helper function.

##  extend()
A helper function for BiBFS, extend(), moves the specified frontier forward by a level and checks for nodes shared between both frontiers' visited sets. extend() additionally enforces forbidden edge and node checks.

## random_title()
A simple random title generator that generates a CSR node converted into a title. random_title() then checks if the randomly generated title is a redirect, in which case it returns its parent node.
